# NotchFlow 第一版功能清单

## 第一版目标

先做一个稳定、顺手、像样的刘海区原型，不追求大而全，重点验证三件事：

- 刘海区交互是否足够自然
- 这块区域是否适合承载高频快捷功能
- 用户会不会愿意把它当成日常入口

## 第一版核心功能

### 1. 应用基础形态

- [ ] 菜单栏常驻应用
- [ ] 后台运行，不显示 Dock 图标
- [ ] 设置窗口
- [ ] 开机自启

### 2. 刘海面板本体

- [ ] 顶部中央悬浮面板
- [ ] 刘海屏定位
- [ ] 非刘海屏降级显示
- [ ] 展开 / 收起动画
- [ ] 多屏基础兼容

### 3. 基础交互

- [ ] 悬停展开
- [ ] 点击固定展开
- [ ] 全局快捷键唤起
- [ ] 一段时间无操作后自动收起

### 4. 第一批功能卡片

- [ ] 正在播放卡片
- [ ] 播放 / 暂停
- [ ] 上一首 / 下一首

### 5. 基础可用性

- [ ] 记住上次基础状态
- [ ] 全屏应用和 Spaces 下行为正常
- [ ] 性能保持轻量

## 第一版增强项

这些功能可以跟着开发进度择机加入，但不作为第一版必须完成的门槛。

- [ ] 快捷启动卡片
- [ ] 计时器卡片
- [ ] 电量卡片
- [ ] 音量和亮度卡片
- [ ] 剪贴板历史预览
- [ ] 日历下一项事件
- [ ] 简单待办卡片
- [ ] Live Activity 风格的紧凑态 / 展开态

## 明确不放进第一版

- [ ] 文件拖放 shelf
- [ ] 电池充电上限控制
- [ ] AI 助手状态卡片
- [ ] AppleScript / Shortcuts 深度联动
- [ ] 会议状态集成
- [ ] 第三方插件系统
- [ ] 云同步

## 我建议的第一版定义

如果只用一句话定义：

> 一个常驻菜单栏的 macOS 刘海工具，支持悬停展开，并优先把“正在播放”这一个高频入口做顺。

## 第一版完成标准

满足下面几点，就可以算第一版成立：

- [ ] 刘海面板能稳定显示和收起
- [ ] 在刘海屏与非刘海屏上都能正常工作
- [ ] 正在播放卡片能可靠展示和控制
- [ ] 基本设置、开机自启、快捷键都可用

## 下一步建议

开发顺序建议按这个来：

1. 菜单栏外壳
2. 刘海面板与定位
3. 悬停 / 点击 / 快捷键交互
4. 正在播放卡片
5. 设置页和开机自启
