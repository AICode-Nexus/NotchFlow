Install

Download the zip, move the app, open once.

  1. Download NotchFlow-v0.1.0-macOS.zip from the GitHub Release.
  2. Unzip and move NotchFlow.app to /Applications.
  3. If macOS blocks the preview build, right-click the app and choose Open.
  4. Enable only the permissions needed for the modules you use.
Release notes

Built for a useful preview, not yet a notarized production installer.

The v0.1.0 release is locally signed and distributed as a simple zip. Developer ID signing, notarization, and a packaged installer are planned after the preview proves the core workflow.
