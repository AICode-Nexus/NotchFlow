Install

Preview build, four steps.

NotchFlow v0.1.0 is locally signed and distributed as a zip while notarized packaging is still pending.

  1. 01 Download

    Get NotchFlow-v0.1.0-macOS.zip from the latest GitHub Release.

  2. 02 Move

    Unzip and move NotchFlow.app into /Applications.

  3. 03 Open

    If macOS blocks first launch, right-click the app and choose Open.

  4. 04 Enable

    Grant permissions only for modules you use, such as location or automation.
